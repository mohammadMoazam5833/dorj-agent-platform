NovaAgent Platform — memari-e system

Vaziat: v1.1 — live Tarikh: 2026-10-05 Scope: web + desktop + CLI, multi-user, mahsool-e mostaghel (joda az Dorj) Mabna: OpenHands Agent Canvas 1.6.5 / agent-server 1.38.0

Khoolase

NovaAgent ye coding agent-e Cursor-class baraye sazman-e: developer dar browser ya terminal task migozare, ye agent dar workspace-e ekhtesasi-e khodesh code mikhoone, minevise, test mikone va natije ro neshoon mide. Hame-ye model-ha az LLM gateway-e sazman (LiteLLM) rad mishan, pas masraf, hazine va dastresi kontrol-shode va ghabel-e gozaresh-an.

Control plane / data plane

nova-control stateless-e: auth, workspace lifecycle, routing, metering. Kar-e agent dar pod-e har karbar.

Yek hoviat, hame ja

nova-control credential-ha ra ba Keycloak realm nova ta'id mikone va opaque tenant-token midahad. CLI/desktop token ro locally negah midaran (desktop: Electron safeStorage); browser HttpOnly cookie migirad. logout token ra server-side revoke mikone.

Workspace-e har karbar

Pod-e OpenHands agent-server + PVC, scale-to-zero vaghti bikar-e, cold-start zir-e 30s.

Model az gateway

Virtual key-e joda baraye har karbar dar LiteLLM: budget, rate limit, model allowlist, trace.

Observability-e sare-be-sar

Prometheus + Grafana, Tempo (OTel trace az ingress ta vLLM), Loki. SLO va alert az roz-e aval.

Tejari az aval

Plan, quota va metering-e token/compute baraye har karbar va har tim (Unit), ghabel-e export baraye billing.

Osool-e mohandesi

  • Separation of concerns: control plane (tasmim-giri) az data plane (ejra-ye agent) joda-st; har kodoom mostaghel scale mishe.
  • Stateless control plane, declarative state: vaziat-e workspace dar Kubernetes (label/annotation, baadan CRD) — nova-control mesl-e ye controller reconcile mikone. Restart-e control plane hich workspace-i ro az bein nemibare.
  • Zero trust dar marz: har request hoviat-e moshakhas dare (OIDC); session key-e agent-server faghat dar control plane-e va be browser nemirese.
  • API-first: web, CLI va baadan IDE extension hame mesl-e ham az /v1 estefade mikonan; API versioned va backward-compatible.
  • 12-factor: config az env/Secret, log be stdout (JSON), process-haye disposable, image-haye immutable ba tag-e daghigh.
  • Least privilege: ServiceAccount-e control plane faghat dar namespace-e workspace-ha ejaze dare; workspace hich dastresi be API-e Kubernetes nadare.
  • Observability by default: RED metrics baraye har service, trace-e OTel ba trace context-e moshtarak az ingress ta model, log-e sakhtar-mand ba user/workspace/conversation.
  • AI engineering: agent ba budget-e token va iteration, context condensation, human-in-the-loop baraye amaliyat-e khatarnak, va eval-e qabl az avaz kardan-e model.

Ettesal be LLM gateway

  • Key-e har karbar: nova-control moghe-e sakhtan-e workspace ba admin key az POST /key/generate ye virtual key ba user_id, team_id (Unit), models, max_budget, tpm/rpm misaze; key dar Secret-e workspace mimoone va hichvaght be browser ya CLI nemire.
  • Address: workspace mostaghim be http://litellm-internal.vllm.svc:4000/v1 vasl mishe (dakhel-e cluster, bedoon-e ingress).
  • Metadata: har call metadata.tags = [nova, user:<id>, ws:<id>, conv:<id>] — gozaresh-e masraf be tafkik-e karbar/tim/conversation az khod-e LiteLLM.
  • Trace: traceparent az nova-control ta agent-server va LiteLLM (ke az ghabl be Tempo vasl-e) va vLLM edame peyda mikone — yek trace az click ta GPU.
  • Quota: hamoon rolling-quota-e mojood-e Dorj (Redis) va budget-e key; residan be had → khata-ye vazeh dar UI/CLI ba zaman-e reset.

  • Tenancy: karbar → Unit (tim/sazman) dar admin panel-e mojood; plan roye Unit, override roye karbar.
  • Metering: token (az LiteLLM spend), compute (saat-e workspace-e roshan × size), storage (GiB-mah). Export-e mahane (CSV/API) baraye billing ya showback.

CLI: nova

# nasb
pipx install nova-cli            # ya binary-e tak-file
nova login                       # username/password → tenant token dar credentials.json
nova whoami                      # karbar, plan, masraf-e in mah
nova run "test-haye auth ro dorost kon" --repo . --model qwen3
nova chat                        # REPL-e interactive ba stream
nova conversations ls | show <id> | resume <id>
nova ws status | start | stop    # workspace-e shoma
nova usage --month               # token · compute · hazine
nova models                      # model-haye mojaz baraye plan-e shoma
nova logout                      # revoke-e server-side token + pak kardan-e local credential

CLI hich key-e LLM ya session key nadare; faghat opaque tenant-token ro dare. Khoroji-e --json baraye script va CI, va exit code-e ma'nadar (0 movaffagh, 2 quota, 3 auth) baraye pipeline-ha.
