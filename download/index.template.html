سؤال‌های پرتکرار

هرچه لازم است بدانید قبل از شروع.

آیا NovaAgent به اینترنت نیاز دارد؟
خیر — همه‌چیز روی شبکهٔ داخلی اجرا می‌شود. کلاینت فقط باید به سرور {{SERVER}} دسترسی داشته باشد؛ کد و داده‌های شما از شبکهٔ بیرون جدا می‌مانند.
داده‌ها و تاریخچهٔ من کجا ذخیره می‌شود؟
روی سرور، داخل workspace اختصاصی خودتان. هر کاربر فضای ایزولهٔ خودش را دارد و هیچ داده‌ای بین کاربران به اشتراک گذاشته نمی‌شود.
اگر سرور عوض شد چه کنم؟
از منوی NovaAgent ← نشانی سرور در خود برنامه، نشانی جدید را وارد کنید (یا متغیر NOVA_SERVER).
به اشتراک AI دیگری یا کلید API نیاز دارم؟
نه. کلاینت به مدل‌های منتخب سازمان متصل می‌شود؛ بدون کلید جداگانه یا اشتراک شخصی.
خط فرمان (CLI) هم دارد؟
بله — nova برای ترمینال و CI. نصب: pip install {{CLI_URL}} سپس nova login و مثلاً nova run "fix the failing tests". گواهی ریشهٔ سازمان: isigpu-root-ca.crt (با NOVA_CA_BUNDLE).
چطور سالم بودن فایل دانلودی را بررسی کنم؟
چکسام همهٔ بسته‌ها در SHA256SUMS است: sha256sum -c SHA256SUMS --ignore-missing
چطور از نسخهٔ قدیمی به نسخهٔ جدید بروم؟
رابط کاربری به‌صورت زنده از سرور بارگذاری می‌شود و بدون نصب مجدد به‌روز می‌شود. فقط برای به‌روزرسانی خودِ کلاینت، نسخهٔ جدید را از همین صفحه دانلود و جایگزین کنید.
